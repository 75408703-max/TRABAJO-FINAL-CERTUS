# Problemática y objetivos

Una universidad necesita asignar a los estudiantes turnos de almuerzo ordenados. El escenario contempla diez franjas de quince minutos desde las 12:00 hasta las 14:30. Se busca distribuir la asistencia, impedir duplicidades en un mismo día y respetar el cupo máximo.

El proyecto aplica Git y GitHub para mejorar trazabilidad, colaboración, revisión e integración de cambios. Las ramas de trabajo se fusionan en `main` únicamente cuando están verificadas.
